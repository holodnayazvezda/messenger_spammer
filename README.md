# messenger_spammer

Небольшой скрипт автоматизации повторного ввода текста в активное окно. Сообщение читается из `spam_text.txt`, вставляется через буфер обмена и отправляется клавишей Enter.

## Использование

```sh
python -m pip install pyautogui pyperclip keyboard
python spammer.py
```

Перед запуском измените текст в `spam_text.txt` и количество повторов в вызове `spam(...)` в `spammer.py` (по умолчанию — 50). После старта есть 5 секунд, чтобы выбрать поле ввода; между вставками выдерживается 0,3 секунды.

Скрипт использует сочетание `Ctrl+V` и управление клавиатурой ОС. Проверяйте его в своём тестовом окне: ввод направляется в текущее активное приложение. В зависимости от системы библиотекам могут потребоваться разрешения на управление клавиатурой.
